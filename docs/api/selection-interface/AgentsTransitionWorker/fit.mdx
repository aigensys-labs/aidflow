  <strong>def AgentsTransitionWorker.fit</strong>(self, inputs, fx_choice=REG.AIG, **params) [[source]](https://github.com/aigensys-labs/aidflow/blob/main/AID/\\TRUENAS\aig_modeling\_Products\AID\1_0_Lib\AID\selector\transition\agents_transition.py#L436)

Execute the full cross-agent transition analysis.

Predicts with all agents, computes pairwise cross-
tabulations, tests significance, and assembles the
complete transition stats.

#### Parameters

**`inputs`** : *`AgentsTransitionInput`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>Container for evaluation data and execution configuration.</div>

**`fx_choice`** : *`str`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>The transition strategy identifier. Defaults to REG.AIG.</div>

**`**params`** : *`dict`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>Runtime parameter overrides, passed to the internal fitter<br />(select_alpha, select_bins).</div>


#### Returns

*`AgentsTransition`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>The fitted model instance containing calculated transition vectors.</div>


<Note>
**Agent Pairs**: By default, all registered agents are
included. Use `transform(data, agents=(1, 3))` to
restrict to specific pairs.
</Note>
