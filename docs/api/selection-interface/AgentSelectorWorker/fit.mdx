  <strong>def AgentSelectorWorker.fit</strong>(self, inputs, fx_choice=REG.AIG, **params) [[source]](https://github.com/aigensys-labs/aidflow/blob/main/AID/\\TRUENAS\aig_modeling\_Products\AID\1_0_Lib\AID\selector\select\agent_selector.py#L551)

Execute the full champion selection pipeline.

Evaluates all agents on the provided data, computes the
diagnostic bundle (performance, SHAP drift, Gini path,
permutation importance), fits the champion agent, and
produces the complete audit package.

#### Parameters

**`inputs`** : *`AgentSelectorInput`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>Input data (OOT/test set) and the champion predictor<br />reference.</div>

**`fx_choice`** : *`str`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>Fitter choice key.</div>

**`**params`** : *`dict`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>Runtime parameter overrides, passed to the internal fitter<br />(select_alpha, select_bins, select_choice).</div>


#### Returns

*`AgentSelector`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>The fitted selector instance holding the promoted champion agent.</div>


<Note>
**Champion Fit**: The champion is fitted via
`AgentPredictor` — it re-fits the model on the selected
feature subset and binds the preprocessing encoders.
The result is a self-contained deployment artifact.
</Note>
