Executes workers for the chosen phase within the defined context scope.

#### Parameters

**`phase`** : *`Literal[all, data, encoding, training, selection]`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>Process workers by the chosen phase or run the whole flow by 'all'.</div>

**`data`** : *`pDF | None`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>Applicable only for phase `'all' or 'data'`.<br />Sideload data already present in memory. When provided,<br />the import step (input_source / input_data) is bypassed<br />entirely — the data is used as-is for downstream processing.</div>

**`verbose`** : *`bool | Verbosity | None = None`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>Verbosity level of workers; None → context default value.</div>
