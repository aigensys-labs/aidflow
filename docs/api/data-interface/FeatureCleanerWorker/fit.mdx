Execute the full data quality screening and type enforcement.

Screens training features against quality gates,
auto-repairs type issues, and enforces the trained
type mapping on the test set.

<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>The fitting strategy identifier. Defaults to REG.AIG.</div>

**`**params`** : *`dict`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>Runtime parameters passed to the internal fitter<br />(max_miss, max_1val, max_var, max_corr, cat_max, downcast).</div>

*`FeatureCleaner`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>The fitted instance with clean feature set and<br />type mapping available.</div>
