Analyze and learn categorical encoding.

Executes the predictive gates, missing handling, and
min-bin-share merging for each categorical feature.
Results are stored as encoding maps ready for
`transform`.

#### Parameters

**`inputs`** : *`CatEncoderInput`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>Input configuration including train_set and<br />categorical feature lists.</div>

**`fx_choice`** : *`str`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>The categorical encoding strategy. Defaults to REG.AIG.</div>

**`**params`** : *`dict`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>Runtime parameters passed to the internal fitter<br />(gini_cutoff, min_bin_share).</div>


#### Returns

*`CatEncoder`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>The fitted encoder instance.</div>
