Analyze and learn numerical bin encoding.

Executes the non-greedy bin search, min-bin-share
merging, and predictive gates for each numerical
feature. Results are stored as encoding maps ready for
`transform`.

#### Parameters

**`inputs`** : *`NumEncoderInput`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>Input configuration including training set and<br />numerical feature lists.</div>

**`fx_choice`** : *`str`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>The numerical encoding strategy. Defaults to REG.AIG.</div>

**`**params`** : *`dict`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>Runtime parameters passed to the internal fitter<br />(max_num_bins, gini_cutoff, num_alpha, min_bin_share).</div>


#### Returns

*`NumEncoder`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>The fitted encoder instance.</div>
