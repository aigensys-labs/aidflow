Analyze the feature set and mine interaction rules.

Trains the shallow GB model, mines interaction rules
from the tree structure, gates on predictive power,
and stores the surviving binary encodings.

#### Parameters

**`inputs`** : *`IxnEncoderInput`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>Configuration including train_set, num_features,<br />and cat_features.</div>

**`fx_choice`** : *`str`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>The interaction mining backend. Defaults to REG.LGB.</div>

**`**params`** : *`dict`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>Runtime parameters passed to the internal fitter<br />(gb_max_leaves, gb_estimators, gb_learning_rate,<br />gb_min_child_weight, ixn_min_target, ixn_min_share,<br />ixn_max_corr, gini_cutoff).</div>

<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>The fitted encoder instance.</div>
