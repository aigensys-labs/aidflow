Apply fitted WOE encodings to new data.

For each encoded feature, produces the WOE numeric value
based on the bin assignment of the input observation.
Unknown values are mapped to the 'Missing' category.

#### Parameters

**`data`** : *`pDF`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>New data containing the original (pre-WOE) features.</div>

**`subset`** : *`list`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>Specific features to process and return (`including IXN`).<br />Default = None: all trained features.</div>


#### Returns

*`WoeEncoderResult`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>WOE-encoded features + full feature lineage metadata.</div>
