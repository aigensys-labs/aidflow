Fit WOE encoding on all encoded features.

For each feature: prunes bins using the selected strategy
(Gini or t-test), computes WOE values, gates on predictive
power, and stores the final encoding.

#### Parameters

**`inputs`** : *`WoeEncoderEnvelope | WoeEncoderInput`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>Input configuration containing train_set, target, and<br />feature lists.</div>

**`fx_choice`** : *`str`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>The bin pruning strategy. Defaults to REG.GINI.</div>

**`**params`** : *`dict`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>Runtime parameters passed to the internal fitter<br />(gini_cutoff, woe_alpha).</div>


#### Returns

*`WoeEncoder`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>The fitted encoder instance.</div>
