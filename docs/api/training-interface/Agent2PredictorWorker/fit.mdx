Train the dense GLM agent on WOE-encoded features.

Executes the full two-stage feature selection pipeline
(regularization search + shadow pruning), fits the
final Logistic Regression, and computes validation
diagnostics.

#### Parameters

**`inputs`** : *`Agent2Input`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>Training configuration including train_set and<br />woe_features.</div>

**`fx_choice`** : *`str`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>The regularization strategy: REG.ELASTIC (default),<br />REG.LASSO, or REG.LOGREG.</div>

**`**params`** : *`dict`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>Runtime parameters passed to the internal fitter<br />(glm_eps, glm_tol, shadow_quantile, cross_val_folds).</div>


#### Returns

*`Agent2Predictor`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>The fitted agent instance.</div>
