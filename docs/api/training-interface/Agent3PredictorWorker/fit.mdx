Train the PLS-optimized GLM agent on WOE-encoded features.

Executes the full two-stage feature selection pipeline
(PLS component analysis + shadow pruning), fits the
final Logistic Regression, and computes validation
diagnostics.

#### Parameters

**`inputs`** : *`Agent3Input`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>Training configuration including train_set and<br />woe_features.</div>

**`fx_choice`** : *`str`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>The fitting strategy identifier. Defaults to REG.AIG.</div>

**`**params`** : *`dict`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>Runtime parameters passed to the internal fitter<br />(glm_alpha, glm_tol, shadow_quantile, cross_val_folds).</div>


#### Returns

*`Agent3Predictor`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>The fitted agent instance.</div>
