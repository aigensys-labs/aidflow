Predict with the Champion Production Agent on input data.

The champion is the final production model selected
during the Selection stage. This is the primary
inference method for production scoring.

**`data`** : *`pDF`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>Input data.</div>

<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>If True, applies the champion's full preprocessing<br />pipeline before prediction. If False, expects<br />pre-processed data.</div>
