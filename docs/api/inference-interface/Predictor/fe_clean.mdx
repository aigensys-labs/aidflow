Validate and clean input data against trained standards.

Applies the trained data-quality pipeline: type
validation, outlier detection, and relevance filtering.
Variables that do not match the trained behavioral
profile are flagged (and optionally removed).

**`data`** : *`pDF`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>Input data of shape (n_samples, n_features).</div>

**`subset`** : *`list`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>Specific features to process and return.<br />Default = None: all trained features.</div>

*`FeCleanerResult`*
