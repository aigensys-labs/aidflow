Apply trained WOE stability filtering.

Removes WOE features that were flagged as unstable
(distribution shift) during training.

#### Parameters

**`data`** : *`pDF | None`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>WOE-encoded data. If None, returns the list of<br />stable WOE features.</div>

**`encode`** : *`bool`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>If True, applies `woe_encode` first (expects<br />binned data). If False, expects WOE-encoded input.</div>


#### Returns

*`WoeStabilizerResult | list`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>• data provided: data subset to stable WOE features only<br />• data is None: list of stable WOE feature names</div>
