Apply trained WOE encoding to input data.

Converts binned features into Weight of Evidence values
using the bin-level target rates locked during training.

#### Parameters

**`data`** : *`pDF | None`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>Input data (binned features). If None, returns the<br />trained WOE encoding map.</div>

**`subset`** : *`list`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>Specific features to process and return (including IXN).<br />Default = None: all trained features.</div>


#### Returns

*`WoeEncoderResult | dict`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>• data provided: data of WOE-encoded features<br />• data is None: trained WOE values per bin</div>
