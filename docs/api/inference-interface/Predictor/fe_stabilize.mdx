Apply trained time-stability filtering to input data.

Removes variables that were detected as unstable
(time-variant distributions) during training. Ensures
only temporally stable features propagate downstream.

#### Parameters

**`data`** : *`pDF`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>Input data of shape (n_samples, n_features).</div>

**`preprocess`** : *`bool`*
<div style={{"paddingLeft": "1.25rem", "marginTop": "0.25rem", "marginBottom": "1rem"}}>If True, accepts original columns and applies<br />`fe_clean` first. If False, expects output<br />from `fe_clean`.</div>

*`FeStabilizerResult`*
